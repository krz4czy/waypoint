# Waypoint

Prosta aplikacja terenowa w języku polskim: nawigacja do maksymalnie trzech celów, pomiar odległości, tracking GPS oraz przybliżony pomiar powierzchni.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Funkcje GPS i kompasu wymagają uprawnień przeglądarki; na urządzeniach mobilnych najlepiej działają przez HTTPS.

## Publikacja

Workflow GitHub Actions `.github/workflows/pages.yml` wdraża aplikację na GitHub Pages po pushu na gałąź `arena/d1b7a9ab-waypoint`. Adres strony: https://krz4czy.github.io/waypoint/.
